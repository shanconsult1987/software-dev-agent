
# Software Development Agent

A small Python application used to demonstrate
agentic software development with GitHub.

## Features

- Task creation
- Task retrieval
- Task status updates
- Priority validation
- Automated tests

## Run

Install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run tests:

```powershell
python -m pytest -v
```
